# Tabi — путешествие по Японии

Учебное веб-приложение: тематический дашборд на чистом JavaScript с ES6 Modules, наследованием, инкапсуляцией и полиморфизмом. Интерфейс на русском, адаптирован для телефона и компьютера. Семь типов виджетов: погода, курс валют, задачи, авторские фразы, маршрут, бюджет, избранные места.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Нельзя открывать index.html через file://: браузер блокирует ES-модули. Альтернатива: любой статический HTTP-сервер с корнем `dist/`. Для статического хостинга публикуйте содержимое `dist/`.

## Структура и архитектура

```text
dist/
  index.html                   — семантическая оболочка, подключение main.js как модуля
  main.js                      — инициализация, диалог добавления, навигация
  js/
    UIComponent.js             — абстрактный базовый класс и безопасный DOM helper
    Dashboard.js               — коллекция, реестр типов, хранение, фильтры
    ApiWidget.js               — базовый API-класс, состояния и отмена запросов
    WeatherWidget.js           — Open-Meteo, выбор города
    CurrencyWidget.js          — Frankfurter, конвертер валют
    ToDoWidget.js              — независимый список задач
    QuoteWidget.js             — независимые авторские фразы
    RouteWidget.js             — пример маршрута
    BudgetWidget.js            — расходы и редактируемый лимит
    PlacesWidget.js            — сохранение понравившихся мест
  styles/
    main.css                   — общая сетка и адаптивность
    components.css             — стили виджетов
server.mjs                     — локальный статический сервер
.openai/hosting.json            — конфигурация хостинга Sites
```

`UIComponent` принимает конфигурацию (`title`, `id`, callbacks), создаёт обёртку через `render()`, предоставляет `minimize()`, `close()`, `serialize()` и `destroy()`. Экземпляр владеет обработчиками через AbortController; destroy() вызывает abort() и удаляет DOM. `ApiWidget` дополнительно отменяет запрос и очищает таймаут. Конкретные классы переопределяют render()/serialize(), а Dashboard работает с единым интерфейсом, не зная деталей класса.

`Dashboard.addWidget(widgetType)` создаёт независимый экземпляр из реестра `widgetTypes`; `removeWidget(widgetId)` вызывает destroy() и удаляет экземпляр из коллекции. Новый тип добавляется в реестр без изменения алгоритмов Dashboard. Кнопки «выше/ниже» переставляют виджеты без перетаскивания и сохраняют фокус. Каждый ToDoWidget хранит собственный массив `tasks`. Состояние всех экземпляров, порядок, свёрнутость, расходы и избранное сериализуются в localStorage. Удалённый виджет больше не подписан на события и не получает ответы API.

## API и источники данных

1. **Open-Meteo**: https://open-meteo.com/en/docs — `https://api.open-meteo.com/v1/forecast`, поля current: температура, код погоды, ветер, влажность. Фиксированные координаты Токио, Киото и Осаки; часовой пояс Asia/Tokyo.
2. **Frankfurter**: https://frankfurter.dev/ — `https://api.frankfurter.dev/v2/rate/USD/JPY` (или EUR/JPY), справочный курс и дата публикации.

Оба API публичные, без секретного ключа. Каждый API-виджет имеет loading, empty, error, success; повторный запрос отменяет предыдущий через AbortController. Таймаут — 12 секунд. Удаление виджета отменяет запрос и таймаут. Формат ответа проверяется; динамический контент API, пользователя и localStorage выводится через textContent/createElement, без innerHTML. Ответы не подменяются демонстрационными данными при ошибке. Обновление явное — кнопкой либо выбором города/валюты.

Изображения: Unsplash (images.unsplash.com), шрифты: Google Fonts (Manrope и DM Sans). Если внешние изображения/шрифты недоступны, сохраняются фон, системный шрифт и работа приложения. Фразы — авторские тексты Tabi, а не цитаты известных людей.

## Доступность и ограничения

Нативные кнопки, формы, checkbox, select и dialog работают с клавиатуры; видимый focus-visible; aria-label у иконок; aria-live для результатов и действий; сохранение фокуса после удаления/перестановки. Перетаскивание не используется, есть кнопочная перестановка. Смена настроек каждого виджета независима. Лимит — 40 виджетов. Уход со страницы освобождает обработчики приложения и виджетов.

Данные хранятся только в текущем браузере, без аккаунта, синхронизации и сервера. При недоступном localStorage интерфейс сообщает, что изменения не сохраняются. Это планировщик, а не сервис бронирования. Маршрут и исходный бюджет — учебные примеры, не актуальные цены или рекомендации. Курс справочный, без банковских комиссий; доступны USD и EUR, RUB не заявлен. Погода текущая, не прогноз для будущей поездки. API могут временно ограничивать запросы; ошибки видны с возможностью повтора. Геолокация пользователя не запрашивается.

## Проверка

```sh
node --test tests/lifecycle.test.mjs
```

Три автоматические проверки: API-состояния loading/success/empty/error; отмена устаревшего и незавершённого запроса и очистка слушателей; независимость массивов задач. В браузере проверены реальные успешные ответы обоих API, создание второго ToDo, добавление/отметка задачи, независимость списков, сворачивание, сохранение после обновления, удаление дополнительного виджета и смена авторской фразы.
